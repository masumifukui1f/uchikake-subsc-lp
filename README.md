# 打掛サブスク LP（横スワイプ型ランディングページ）

全国の美容室オーナー様向け、婚礼和装サブスクサービス「打掛サブスク」（運営：株式会社真寿美衣裳／ブライダルマスミ）の**横スワイプ型ランディングページ**です。

- 単一の `index.html` で動く**静的サイト**（ビルド不要・外部ライブラリなし）
- スマホ＝指スワイプ、PC＝左右ナビ／キーボード←→／マウスホイールで横移動
- 料金・価格・プランの記載は一切ありません（仕様）

---

## 1. ファイル構成

```
uchikake-subsc-lp/
├─ index.html        ← LP本体（これ1枚で動きます）
├─ README.md         ← この説明書
└─ images/           ← 差し替え用の画像フォルダ
   └─ README.txt     ← どの画像をどのファイル名で入れるかの一覧
```

画像が入っていない間は、LP上に**点線枠＋「どんな画像が入るか」のラベル**が表示されます。画像を入れると自動でその画像に切り替わります。

## 2. ローカルでの確認方法

いちばん簡単な方法：

- `index.html` を**ダブルクリック**してブラウザ（Chrome / Edge / Safari）で開くだけ。

> Google Fonts（明朝・ゴシック）の読み込みにインターネット接続が必要です。オフラインだと書体だけ標準フォントになりますが、表示・動作には問題ありません。

ローカルサーバで開きたい場合（任意・画像のキャッシュ確認などに便利）：

```bash
# Python が入っている場合（このフォルダ内で実行）
python -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 3. GitHub Pages での公開手順

### 3-1. GitHub にリポジトリを用意して公開する

1. GitHub で新しいリポジトリを作成（例：`uchikake-subsc-lp`）。**Public** を選びます。
2. このフォルダの中身（`index.html` / `README.md` / `images/`）をリポジトリに push します。
   - 具体的なコマンドは、別途ご案内する「GitHub 公開手順」に沿って進めてください。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** を **「Deploy from a branch」** にします。
5. **Branch** を **`main`**、フォルダを **`/ (root)`** に設定して **Save**。
6. 数十秒〜数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

> ポイント：公開URLは「リポジトリ名」を含む形になります。`index.html` がリポジトリの**いちばん上の階層（root）**にあることが大切です。

### 3-2. 公開後の更新

ファイルを直して再度 push すれば、自動で公開ページに反映されます（反映まで数十秒〜数分かかることがあります）。

## 4. 画像の差し替え手順

1. `images/` フォルダ内の **README.txt** を開き、必要な画像とファイル名を確認します。
2. 下記のファイル名で、`images/` フォルダに画像を置きます（**同じ名前で上書き**するだけ）。

   | ファイル名 | 入れる画像 | 形 |
   |---|---|---|
   | `images/01-hero.jpg` | 表紙メイン：打掛・白無垢の着姿 | 横長 |
   | `images/03-wedding.jpg` | 和装フォトウェディングの一場面 | 横長 |
   | `images/06-collection.jpg` | 衣裳棚にずらりと並ぶ打掛 | 横長 |
   | `images/07-care.jpg` | お手入れ・メンテナンス風景 | 縦長 |
   | `images/08-montsuki.jpg` | 紋付袴姿の新郎 | 縦長 |

3. ブラウザを再読み込みすると、画像が反映されます。
4. `.png` や `.webp` を使いたい場合は、`index.html` 内の該当ファイル名の**拡張子も同じものに**直してください（`images/01-hero.jpg` → `images/01-hero.webp` など）。

> 画像を入れ替えてもレイアウトは崩れません（枠サイズに合わせて自動でトリミング表示されます）。容量の大きい写真は、表示を軽く保つため横1200px程度に縮小しておくのがおすすめです。

## 5. 色・文言の変更（メンテ用メモ）

- **色を変えたいとき**：`index.html` 先頭の `:root{ ... }`（デザイントークン）の値だけ書き換えると、全体の配色が一括で変わります。
  - 深藍 `--navy` ／ 金 `--gold`・`--gold-light` ／ 生成り `--cream` ／ 本文 `--ink` など。
- **文言を変えたいとき**：各 `<article class="slide ...">` の中の見出し（`h2`）・本文（`p`）・リスト（`li`）を書き換えます。改行したい位置に `<br>` を入れると整います。
